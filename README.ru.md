# Volt.py

**Версия 1.0**

[English version](README.md)

Консольная текстовая симуляция мира: вы описываете мир, ИИ оживляет его, а дальше
вы просто пишете, что делаете, и смотрите, как мир реагирует.

Всё работает в одном процессе и в одном терминале. Никаких вторых окон,
вебсокет-сервера и внешних GUI-диалогов.

Форк [ThetaInterface/volt](https://github.com/ThetaInterface/volt), переписан на
Python — см. [Отличия от оригинала](#отличия-от-оригинала).

```
Volt.py
├── volt/                 пакет с кодом
│   ├── models/           мир, актёры, локации, время
│   ├── engine.py         обращения к LLM (стриминг, отмена)
│   ├── game.py           игровой цикл: ввод, очередь, фоновые события
│   ├── ui.py             меню, настройки, мастер создания мира
│   ├── console.py        цвета, ввод с таймаутом, «печатная» реплика ИИ
│   ├── config.py         типизированные настройки
│   ├── saves.py          файлы сохранений
│   └── prompts.py        тексты промтов
└── assets/locales/       ru.json, en.json
```

## Требования

Python 3.9 или новее. Сторонних библиотек нет — только стандартная
библиотека, сборка не нужна.

## Быстрый старт

```bash
python Volt.py
```

В главном меню пять пунктов: «Играть», «Сохранения», «Настройки», **«Об игре»**
(версия, автор, активный провайдер и расположение файлов) и «Выход».

Дальше: **Настройки** → вставьте API-ключ Aika AI и выберите модель, затем
**Играть** → **Новый мир** → опишите мир несколькими строками.

Описание заканчивается пустой строкой или одиночной точкой. Генерация мира
занимает от десятков секунд до пары минут.

### Флаги командной строки

| Флаг | Что делает |
|---|---|
| `--saves` | показать список сохранений и выйти |
| `--lang ru\|en` | сменить язык интерфейса (сохраняется в `config.json`) |
| `--no-color` | отключить цвета |
| `--debug` | складывать сырые ответы ИИ в `./debug/` |
| `--version` | показать версию и выйти |

Переменные окружения: `NO_COLOR`, `VOLT_PY_FORCE_COLOR`, `VOLT_PY_DEBUG`.

## Провайдер ИИ

По умолчанию используется **Aika AI**
(`https://api.aika-ai.com/v1/chat/completions`). Достаточно вставить API-ключ и
выбрать модель в настройках:

* **aika** — Aika AI, 60+ моделей (GPT, Claude, Gemini, DeepSeek, Qwen, GLM,
  Kimi, Grok, Llama и другие);
* **custom** — любой другой OpenAI-совместимый провайдер: URL, ключ, модель.

При выборе модели Volt.py может сам загрузить список у провайдера
(`/v1/models`) — ввести имя вручную тоже можно. Aika AI отдаёт в списке
красивые имена (`ChatGPT-4o`), а в запрос уходит технический идентификатор
(`gpt-4o`); в настройках видны оба.

Если провайдер не поддерживает `response_format`, Volt.py один раз повторит
запрос без него.

## Как играть

В игре вы пишете действие обычным текстом — никаких цифровых меню:

```
2026Y5M2D 08:15:00 > осмотреть кухню

Ты включаешь чайник. Из-за стены слышны шаги.

2026Y5M2D 08:18:00 > подойти к окну
```

Служебные команды начинаются со слэша:

| Команда | Что делает |
|---|---|
| `/help` | список команд |
| `/look` | осмотреть текущую локацию — без обращения к ИИ |
| `/state` | состояние мира: время, игрок, локация, потребности, события |
| `/who` | кто рядом |
| `/inventory` | инвентарь игрока |
| `/wait N` | подождать N минут |
| `/cancel` | отменить текущую генерацию |
| `/revert` | откатить последний ход |
| `/save` | сохранить немедленно |
| `/reload` | показать последнюю реплику ещё раз |
| `/log` | последние строки лога |
| `/exit` | выйти из игры |

Короткие синонимы, тоже после слэша: `/q` `/quit` — выход, `/?` `/h` — помощь,
`/l` — осмотр, `/i` — инвентарь, `/w` — ждать, `/s` — сохранить,
`/r` — повторить реплику. Строка `exit` (настраивается как «стоп-фраза») также
выходит из игры и без слэша.

### Что происходит, пока вы печатаете

Генерация идёт в фоновом потоке, поэтому:

* `/cancel` работает сразу, не дожидаясь конца генерации;
* действия, введённые во время генерации, ставятся в очередь и уходят сразу
  после неё;
* фоновые события печатаются, не сбивая набираемую строку: каждый вывод
  стирает и заново рисует активную строку ввода.

Печать реплик идёт посимвольно; скорость настраивается параметром «Скорость
печати текста» (`1.0` — мгновенно, без анимации).

### Мир живёт сам

Пока вы не вводите команды, мир продолжает жить:

* раз в `localEventInterval` секунд (по умолчанию 300) с нарастающей
  вероятностью происходит локальное событие — время идёт, NPC действуют;
* при смене суток автоматически генерируется мировое событие;
* при отменённой генерации события время откатывается, чтобы в мире не
  появился пропуск без описания.

Отключается это в настройках: **Локальные события**.

## Настройки

Меню **Настройки** показывает все параметры списком; номер меняет значение,
`0` возвращает назад, `r` сбрасывает всё к умолчаниям. Значения сохраняются в
`config.json` сразу.

| Ключ | Смысл |
|---|---|
| `aiProvider` | провайдер: `aika` или `custom` |
| `aikaApiKey` | API-ключ Aika AI |
| `aikaModel` | модель Aika AI, например `gpt-4o-mini` |
| `customProviderUrl` / `customProviderApiKey` / `customProviderModel` | свой провайдер |
| `language` | язык интерфейса (`ru`, `en`) |
| `exitPhrase` | слово, которым выходят из игры |
| `textSpeed` | скорость печати реплик, `0`–`1` |
| `temperature` | температура выборки, `0.1`–`1.0` |
| `generateLocalEvents` | включить фоновые локальные события |
| `localEventInterval` | базовый интервал локальных событий, секунды |
| `regenerateAttempts` | сколько раз повторять генерацию события |
| `messageHistorySize` | сколько последних сообщений хранить |
| `worldHistorySize` / `worldEventsSize` / `worldRumorsSize` | лимиты данных мира |
| `actorMemorySize` / `actorKnowledgeSize` | лимиты памяти и знаний актёра |
| `logRotation` / `logRotationLimit` | ротация `log.txt` по числу строк |

## Файлы рядом с программой

| Путь | Что это |
|---|---|
| `config.json` | настройки, создаётся при первом запуске |
| `saves/` | сохранения, по одному JSON на мир: `{id}_{дата}.json` |
| `log.txt` | ошибки и предупреждения |
| `debug/` | сырые ответы ИИ, только при `--debug` |

Папку можно просто скопировать целиком — мир, настройки и логи переедут вместе
с программой.

## Как это устроено

Мир хранится одним JSON: локации, актёры с потребностями, памятью и знаниями,
история, слухи, скрытая история (то, чего игрок не знает) и флаги мира.

На каждое действие ИИ возвращает `narration` (то, что видит игрок) и список
`stateChanges` — команды изменения состояния: `moveActor`, `addMemory`,
`setNeed`, `addCurrentEvent`, `addHiddenHistory` и ещё несколько десятков.
Volt.py применяет их и сохраняет файл. Поэтому откат — это просто
восстановление предыдущего снимка, а не перегенерация.

Промты лежат в `volt/prompts.py` и правятся как обычный текст: отдельно для
генерации мира, действия игрока, локального события и мирового события.

## Отличия от оригинала

Оригинал — консольное приложение на Dart, разбитое на клиент и «сервер», которые
общались по WebSocket на `127.0.0.1:9999`. Сервер открывался в отдельном окне
терминала, а ввод текста шёл через внешний диалог на C++.

Здесь всё это убрано:

| | Было | Стало |
|---|---|---|
| Процессы | клиент + WebSocket-сервер, два окна | один процесс, один терминал |
| Ввод | цифровые меню + GUI-диалог (`dialog.exe`) | обычный текст и команды `/` |
| Отмена | работала только между ходами | `/cancel` прерывает генерацию сразу |
| Очередь | не было | действия во время генерации ждут своей очереди |
| Интерфейс | только русский, `en.json` был почти пустым | полные `ru` и `en`, переключение в настройках |
| Провайдеры | отдельный SDK для Mistral | один OpenAI-совместимый клиент, по умолчанию Aika AI |
| Зависимости | Dart SDK + CMake + сборка | только стандартная библиотека Python |

Модель мира, формат сохранений и тексты промтов сохранены: промты перенесены
почти дословно, изменилось только упоминание языка в инструкциях модели. Все 42
типа `stateChanges`, описанные в промтах, реализованы.

Переписан код применения изменений — в оригинале он содержал ошибки:

* проверка `addActor` была инвертирована, из-за чего актёр мог добавиться дважды;
* неполный `updateActor` от модели затирал локацию, потребности и возраст;
* повторный `addCurrentEvent` с тем же `id` плодил дубликаты — теперь запись
  обновляется по месту;
* `Time` считал секунды по-разному при сравнении и при прибавлении;
* мировые события генерировались по промту локальных.
